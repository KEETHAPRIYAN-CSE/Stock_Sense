# Frontend Agent Prompt Template

When working on frontend tasks for StockSense:
1. Review `BUILD_STOCKSENSE.md`, Section 49 wireframe guidance, and `.agents/rules/frontend.md`.
2. Adhere to the dark modern aesthetic: `#0f172a` dark background, `#1e293b` surfaces, `#FF5C5C` coral accent, light text.
3. Every page must support: Loading, Empty, Error, and Success states.
4. Verify all forms validate required inputs and confirm critical operational steps (e.g. Validate Receipt, Deliver Stock).
5. Ensure type safety using TypeScript interfaces matching backend Pydantic schemas.
