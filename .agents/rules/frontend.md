# Frontend Development Rules

1. Use React, TypeScript, and Vite with clean modular architecture.
2. Follow the design system from the wireframes: dark theme, high contrast surfaces, coral/pink accent (`#FF5C5C` or `--accent`), crisp typography, subtle borders.
3. Every screen must handle all states: Loading, Empty, Error, Success, Form Validation, Confirmation Dialogs, and Disabled Actions.
4. Never hard-code business data or mock inventory values into the UI.
5. Provide responsive desktop-first layout with smooth mobile-friendly collapsible navigation.
6. Strictly type all API responses and component props in TypeScript.
